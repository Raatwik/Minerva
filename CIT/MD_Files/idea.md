# VaultDrive

**Project Idea:**
A zero-trust, offline "airlock" gatekeeper for critical infrastructure that transforms a standard USB drive into an intelligent edge-agent. It intercepts, scans, and verifies data transfers using offline security checks (YARA, Shannon Entropy analysis, and Data Loss Prevention) to prevent malware infection and data exfiltration in air-gapped environments. Once the USB is plugged into an internet-connected admin machine, it acts as a bridge, automatically syncing the offline event logs and threat data to a centralized SaaS dashboard for security monitoring.
